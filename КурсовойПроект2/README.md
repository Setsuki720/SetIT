# Генератор случайных вызовов

## Описание
Веб-приложение для генерации случайных квестов (вызовов), направленных на саморазвитие, творчество и коммуникацию. Пользователь может получать задания, отслеживать прогресс, зарабатывать награды и вести историю выполненных действий.

## Функционал
- 🎲 Генерация случайных квестов с учётом фильтров по сложности и категориям
- 👤 Профиль пользователя с именем, уровнем, статистикой и датой регистрации
- 📜 История всех полученных, выполненных и пропущенных квестов
- 🏅 Система наград за серии выполненных заданий (3, 5, 7 дней)
- ⚙️ Настройки фильтров по умолчанию и сброс всего прогресса
- 💾 Сохранение данных в LocalStorage браузера

## Технологии
- HTML5
- CSS3 (Стилизация)
- JavaScript (ES6+ модульная структура)
- LocalStorage API
